# Student CRUD Application

## Project Description
A Student Record Management System developed using HTML, CSS, and JavaScript.

## Features
- Add student records
- View student records
- Edit student details
- Delete student records
- Validate student inputs
- Store data using browser localStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add, view, edit, and delete student records.
